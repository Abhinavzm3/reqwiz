
ReqWiz is a MERN-stack API client for composing, sending, and managing HTTP requests with a modern UI.

Features
Send GET, POST, PUT, DELETE requests

Manage query params, headers, and JSON body

Organize requests in collections

View request history and responses

User authentication with JWT

Tech Stack
Frontend: React, Redux, Tailwind CSS

Backend: Node.js, Express, MongoDB, JWT

Usage
Register and log in simply..

Compose and send requests

Save requests to collections

View history and results
